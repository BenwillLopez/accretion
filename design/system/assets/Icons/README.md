The web store's own glyphs on a 24px grid, copied from its markup and scripts. Filled: `search`, `heart`, `bell`. Stroked at 2px with round caps and joins: `download`, `copy`, `cert`. On the site they are inline SVG in `currentColor`; these files are drawn in `muted` dark (#8b87b3) because an image can't inherit colour, so inline the path when the colour must follow a token. The app uses SF Symbols instead.
